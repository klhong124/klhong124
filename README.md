# Ryan Kwan Portfolio v2

Cinematic, systems-first portfolio built with Next.js 15, TypeScript, TailwindCSS, Motion, GSAP, and MDX case studies.

## Features

- Immersive single-page experience with modular sections
- BuiltByPixel role and latest experience highlights
- MDX project case studies (`/work/[slug]`)
- Command palette (cmd/ctrl + K)
- Accent theme variants (cyan, violet, amber)
- Contact API route and SEO routes (`sitemap.xml`, `robots.txt`)

## Run locally

```bash
npm install
npm run dev
```

## Stack

- Next.js 15 (App Router)
- React 18 + TypeScript
- TailwindCSS + SCSS tokens
- Motion + GSAP + Lenis
- React Three Fiber (project supports 3D extensions)
