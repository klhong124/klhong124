### 🗺 How I Work
- 🧱 **Build the primitives first** — shared components and tokens before features, so the next screen is assembly rather than invention.
- 🎬 **Motion is information** — animation should tell you where you are, what changed, and what is loading. Anything else gets a reduced-motion switch.
- 🛡 **Types at the edges** — validate API responses and authored content at the boundary so the rest of the app can trust its data.
- 🔮 **Optimise for the next maintainer** — boring, obvious code; save the cleverness for the interaction design.
